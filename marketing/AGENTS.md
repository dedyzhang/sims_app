# Panduan AI — Edutive Marketing

## Nama proyek

**Edutive Marketing** — materi promosi untuk aplikasi SIMS_MW_APP.

## Proyek ini mengerjakan apa

- Landing page promosi Edutive: beranda, fitur, paket, dan kontak.
- Screenshot asli aplikasi yang dapat diperbesar tanpa blur.
- Presentasi PowerPoint dan materi demo untuk calon klien sekolah.

## Aturan dasar untuk AI

1. Bekerja dari folder `D:\SIMS_MW_APP\marketing` dan baca `AGENTS.md` serta `README.md` sebelum mengubah apa pun.
2. Ambil klaim fitur dari source code, route, UI, dokumentasi, atau test SIMS_MW_APP. Jangan mengarang fitur, angka dampak, harga, testimoni, atau integrasi.
3. Gunakan nama **Edutive**, istilah **Asisten Guru**, font **Plus Jakarta Sans**, serta warna utama biru, kuning, dan putih.
4. Gunakan screenshot asli aplikasi. Jangan blur, jangan crop bagian penting, dan pertahankan fitur klik untuk zoom.
5. Semua copy untuk klien menggunakan Bahasa Indonesia yang hangat, ringkas, dan berorientasi manfaat.
6. Jangan mengubah file di luar folder `marketing` kecuali diminta secara eksplisit. Pertahankan pekerjaan lain di repository.
7. Setelah perubahan visual, jalankan `node capture-landing-preview.mjs`. Jika klaim fitur berubah, jalankan test aplikasi yang relevan.
8. Jangan commit, push, deploy, mengirim lead, atau mempublikasikan website tanpa permintaan eksplisit FL.
